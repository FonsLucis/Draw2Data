# Roadmap

## 프로젝트 비전
Draw2Data는 누구나 직관적으로 금융 시나리오를 그리고, 시뮬레이션하고, 공유할 수 있는 플랫폼을 목표로 합니다.

---

## Phase 1: 정적 MVP (현재 단계) ✅

**목표:** 핵심 기능을 검증할 수 있는 최소 기능 제품 출시

**기간:** 완료

**주요 기능:**
- ✅ 캔버스 기반 가격 궤적 그리기
- ✅ 일봉/주봉/월봉 데이터 생성
- ✅ Buy & Hold 시뮬레이션
- ✅ KPI 계산 (Final Value, Cum Return, CAGR, MDD)
- ✅ CSV 다운로드
- ✅ 브라우저 전용 (서버 불필요)

**기술 스택:**
- HTML/CSS/JavaScript (Vanilla)
- 외부 라이브러리 없음

**배포:**
- GitHub Pages
- Netlify
- Vercel
- 또는 임의의 정적 호스팅

**성공 지표:**
- 사용자가 5분 이내에 첫 시뮬레이션 완료
- CSV 다운로드 기능 정상 작동
- 모바일 브라우저에서도 사용 가능

---

## Phase 2: 웹 플랫폼 전환 (다음 단계) 🚀

**목표:** 사용자 계정, 프로젝트 저장, API 기반 아키텍처 구축

**기간:** 3-6개월 예상

### 2.1 사용자 관리 및 인증
- [ ] 회원가입 / 로그인 (이메일 + 비밀번호)
- [ ] OAuth 지원 (Google, GitHub)
- [ ] JWT 기반 인증
- [ ] 사용자 프로필 관리

### 2.2 프로젝트 및 데이터 저장
- [ ] 프로젝트 생성/수정/삭제
- [ ] 그림(Drawing) 저장 및 불러오기
- [ ] 시나리오 저장 및 관리
- [ ] 클라우드 스토리지 연동

### 2.3 Backend API 구축
- [ ] RESTful API 또는 GraphQL
- [ ] PostgreSQL 데이터베이스
- [ ] Redis 캐싱
- [ ] API 문서화 (Swagger/OpenAPI)

### 2.4 비동기 시뮬레이션 처리
- [ ] Redis 큐 도입
- [ ] Worker 프로세스 분리
- [ ] Run 상태 추적 (queued, running, completed, failed)
- [ ] 결과 S3 저장

### 2.5 Frontend 리팩토링
- [ ] React + TypeScript로 재작성
- [ ] 상태 관리 (Zustand/Redux)
- [ ] 반응형 UI 개선
- [ ] 로딩 상태 및 에러 핸들링 강화

**기술 스택:**
- Frontend: React, TypeScript, TailwindCSS
- Backend: Node.js + Express or FastAPI (Python)
- Database: PostgreSQL
- Queue: Redis + Celery (or Bull)
- Storage: AWS S3 or MinIO

**배포:**
- Frontend: Vercel/Netlify
- Backend: AWS ECS, Heroku, or DigitalOcean
- Database: AWS RDS or managed PostgreSQL

**성공 지표:**
- 100명 이상의 등록 사용자
- 평균 세션 시간 10분 이상
- 프로젝트 저장 및 불러오기 성공률 99% 이상
- API 응답 시간 < 200ms (p95)

## Phase 3: 고급 기능 및 커뮤니티 (장기) 🌟

**목표:** 플랫폼 생태계 구축 및 사용자 커뮤니티 활성화

**기간:** 6-12개월 예상

### 3.1 공유 및 협업
- [ ] 시나리오 공유 링크 생성
- [ ] 읽기 전용 임베드 위젯
- [ ] 프로젝트 멤버 초대
- [ ] 실시간 협업 (WebSocket)

### 3.2 템플릿 마켓플레이스
- [ ] 사용자 생성 템플릿 업로드
- [ ] 템플릿 갤러리 및 검색
- [ ] 템플릿 평가 및 댓글
- [ ] 인기 템플릿 랭킹
- [ ] 프리미엄 템플릿 (유료)

### 3.3 고급 시뮬레이션
- [ ] 멀티 에셋 포트폴리오
- [ ] 커스텀 거래 전략 (Python DSL)
- [ ] 리밸런싱 전략
- [ ] 옵션 전략 시뮬레이션
- [ ] 몬테카를로 시뮬레이션

### 3.4 분석 및 리포팅
- [ ] 대시보드 (여러 시나리오 비교)
- [ ] 차트 시각화 (Plotly, Recharts)
- [ ] PDF 리포트 생성
- [ ] 이메일 리포트 전송

### 3.5 모바일 앱
- [ ] React Native 앱
- [ ] 터치 최적화 그리기 인터페이스
- [ ] 푸시 알림 (시뮬레이션 완료)

### 3.6 교육 및 문서
- [ ] 튜토리얼 비디오
- [ ] 사용 가이드 문서
- [ ] FAQ 및 헬프센터
- [ ] 블로그 (전략 아이디어, 사례 연구)

**기술 스택:**
- 기존 스택 + WebSocket (실시간 통신)
- Kafka or RabbitMQ (고급 이벤트 처리)
- Elasticsearch (검색 기능)
- CDN (글로벌 배포)

**성공 지표:**
- 1,000명 이상의 활성 사용자 (MAU)
- 100개 이상의 공유 템플릿
- 평균 사용자당 5개 이상의 프로젝트
- 플랫폼 내 거래 전략 실행 1,000회 이상

## 비즈니스 모델 (선택적)

**Free Tier:**
- 프로젝트 3개 제한
- 월 10회 시뮬레이션 실행
- 기본 전략만 사용 가능

**Pro Tier ($9.99/month):**
- 무제한 프로젝트
- 무제한 시뮬레이션
- 고급 전략 및 멀티 에셋
- 우선 지원

**Enterprise Tier (Custom):**
- 팀 협업 기능
- 전용 인프라
- API 접근
- 맞춤형 기능 개발

## 기술 부채 관리

각 Phase에서 기술 부채를 최소화하기 위한 원칙:

1. **코드 리뷰:** 모든 PR은 최소 1명 이상 리뷰
2. **테스트:** 핵심 로직 테스트 커버리지 80% 이상
3. **문서화:** API 및 주요 모듈 문서화
4. **리팩토링:** 분기당 1회 리팩토링 스프린트
5. **모니터링:** 에러 추적 (Sentry) 및 성능 모니터링 (DataDog/New Relic)
